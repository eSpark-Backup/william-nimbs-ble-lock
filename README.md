# Smart Locking System Design
#### Description: Ultra-low-power smart locking system with solar charging
#### Client Name: William Nimbs

## Project Requirements
The hardware must support / provide below features:
- BLE Module Selection & Integration
    - Must be ultra-low-power for long battery life.
    - Secure connection for unlocking/control remotely.
- Electronic Locks (Link will be provided by client soon)
    - Efficient electromagnetic or solenoid locks.
    - Low power draw with momentary activation.
- Battery Management
    - LiFePO4 battery (around 12V, ~3Ah) for long-term use. Subject to change based on Engineering input for achieving desired backup time
    - Smart power handling for efficient energy usage.
    - Intended backup time is 12 months before requiring a recharge.
    - Expected Usage is about 20 times in a single day
- Solar Panel Integration
    - Small, efficient solar panel to trickle-charge the battery. Preferably the soft version.
- LED Lights
    - Required in each compartment. Quantity to be determined from Engineering side that has sufficient illumination
 
- Outputs
    - 6 x Outputs / Locks to be operatable at one time.
